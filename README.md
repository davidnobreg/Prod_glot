# GLOT ERP

Sistema ERP/imobiliário desenvolvido em Django com arquitetura modular.

---

# Visão Geral

O GLOT é um sistema focado em:

- gestão de clientes
- vendas
- empreendimentos
- documentos
- cobrança
- dashboard administrativo
- mensageria

---

# Stack Principal

- Python
- Django
- Django REST Framework
- Bootstrap
- AdminLTE
- Jazzmin
- CKEditor
